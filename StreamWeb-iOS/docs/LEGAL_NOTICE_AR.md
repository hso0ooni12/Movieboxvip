# تنبيه حقوق المحتوى والاستخدام

هذا المشروع عبارة عن متصفح مخصص باستخدام WKWebView. لا يتضمن ملفات أفلام أو خوادم بث أو أدوات تنزيل أو تجاوز DRM.

قبل توزيع التطبيق، يجب التأكد من:

- امتلاك الموقع أو وجود إذن لاستخدامه داخل تطبيق iOS.
- وجود حقوق عرض المحتوى في المناطق المستهدفة.
- السماح باستخدام اسم الموقع وشعاره وصوره.
- توافق الاستخدام وميزة حجب الإعلانات مع شروط الموقع والقوانين المطبقة.
- عدم تمكين تنزيل أو تحويل أو مشاركة وسائط دون تصريح.

صاحب الحساب والموزع مسؤولان عن المحتوى والخدمات والرابط المستخدم.
